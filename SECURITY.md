# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.
Use GitHub's **Report a vulnerability** option on the repository's Security
page to send a private advisory to the maintainers.

Include the affected version, steps to reproduce, impact, and any suggested
mitigation. Do not include real credentials, private browsing data, or other
sensitive information in a report.

If private vulnerability reporting is unavailable, contact the repository
owner through their GitHub profile and request a private reporting channel.

## Supported versions

Security fixes are made to the latest version on the `main` branch. Older
versions may not receive fixes.
