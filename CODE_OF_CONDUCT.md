# Code of Conduct

Nebula is a community project. Participants are expected to be respectful,
constructive, and welcoming in issues, reviews, and other project spaces.

Unacceptable behavior includes harassment, personal attacks, deliberate
intimidation, and publishing another person's private information without
permission.

Project maintainers may edit or remove contributions and may limit participation
when conduct harms the community. Report concerns privately to the repository
owner through GitHub.
